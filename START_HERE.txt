WAYPOINT CORE EN - START HERE

Purpose
- Clean English test build for offline Windows laptop testing.
- No CAR demo records, photos, documents, objects, links, or CAR map package.
- Data should start empty.

1. Start Waypoint
   Double-click "Open Waypoint Core.vbs".

2. Local addresses
   - Backend:  http://127.0.0.1:8000
   - Frontend: http://127.0.0.1:5174

3. Stop Waypoint
   Double-click "Close Waypoint Core.vbs".
   This stops recorded Waypoint processes and clears ports 8000/5174.

4. Quick test workflow
   - Field Reports: create a report. If you enter a position, enter BOTH latitude and longitude.
   - Map: click "Choose report position", then click the map. The Field Report form opens with that position filled.
   - Photos: upload a small JPEG. GPS photos should create blue map points.
   - Documents: upload a small TXT or CSV with a coordinate like "10.0, 5.0".
   - Field Objects: create a vehicle or location. Add a position if you want it on the map.
   - Map: confirm report/photo/document/object/manual pins appear and source buttons work where available.
   - Timeline: confirm reports, photos, documents, and event objects appear where available.
   - Connections: create a link and confirm it appears in the list and visual graph.

5. Offline map
   Runtime map files are local GeoJSON under frontend/public/maps/test/.
   The included map is a tiny test package, not an operational basemap.

6. Current limits
   - No online map APIs.
   - No cloud services or accounts.
   - No AI or SIGINT modules.
   - Document extraction is local and simple. TXT/CSV are the best test formats.
   - The test map is intentionally lightweight for old hardware.

7. ToughBook transfer
   Read START_HERE_ToughBook.txt before copying to a thumb drive.
